# Изменения

## 1.5

- Две сборки из одного кода: **open** — публичная, без встроенных плейлистов (свой плейлист по ссылке или из файла); **full** — со встроенными плейлистами из `app/src/full/res/values/presets.xml` (файл не входит в репозиторий).
- Встроенные плейлисты задаются ресурсом, а не кодом; если их нет, раздел «Готовые плейлисты» не показывается.

## 1.4

- **Категории в плеере:** в списке каналов нажмите «влево» ещё раз — слева откроется список категорий (Избранное, Все каналы, группы). При перемещении по категориям справа сразу видны их каналы, видео продолжает идти на фоне.
- Если включить канал из другой категории, ↑/↓ дальше листают эту категорию; после выхода из плеера главный экран тоже откроется на ней.
- «Назад» сначала скрывает категории, затем список. На планшете категории открываются нажатием на заголовок списка («‹ …»).

## 1.3.2

- Ползунки яркости и громкости в стиле YouTube: тонкая вертикальная полоса без подложки, процент сверху, иконка снизу.
- Ползунок показывается на противоположной от пальца стороне: громкость (свайп справа) — слева, яркость (свайп слева) — справа.

## 1.3.1

- Индикаторы яркости и громкости стали вертикальными: яркость показывается у левого края, громкость — у правого (там, где ведёте пальцем).

## 1.3

- **Жесты в плеере (планшет):** свайп вверх/вниз по левой половине экрана — яркость, по правой — громкость; по центру показывается индикатор с процентами.
- Яркость, выставленная в плеере, запоминается и действует только в плеере (системная яркость не меняется).
- Переключение каналов на планшете теперь горизонтальным свайпом: влево — следующий, вправо — предыдущий (вертикальный свайп занят яркостью и громкостью).

## 1.2

- **Встроенные плейлисты** на экране «Плейлисты» — добавляются одним нажатием, повторное нажатие переключает на уже скачанный.
- Если основной адрес встроенного плейлиста недоступен, он скачивается через зеркало; приложение запоминает, какой адрес сработал.
- Первый запуск: кнопка «Выбрать плейлист» ведёт сразу к готовым плейлистам.
- Поддержка потоков DASH (`.mpd`) и Smooth Streaming (`.ism`).
- Исправлено: приложение закрывалось при запуске канала в формате DASH (например, «Первый канал»); неподдерживаемые форматы теперь показывают ошибку.

## 1.1

- Настройки (шестерёнка в шапке главного экрана).
- **При запуске:** список каналов / последний канал / канал из избранного / выбранный канал.
- **Автозапуск при включении ТВ:** BapukTV открывается сам после загрузки устройства.
- Исправлено: после возврата из плеера иногда открывалась не та группа.
- Исправлено: плохо читаемый текст у строки в фокусе на экранах плейлистов и настроек.

## 1.0
