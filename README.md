# BapukTV

Быстрый и простой IPTV-плеер для **Android TV** и **планшетов на Android** (5.0+).

## Что умеет

- Плейлисты M3U/M3U8 **по ссылке** или **из файла** (несколько плейлистов, переключение, обновление, переименование, удаление). Встроенных плейлистов и каналов в приложении нет — смотрите свои.
- Плейлист можно открыть прямо из файлового менеджера (.m3u / .m3u8).
- Плейлист по ссылке сохраняется локально и открывается мгновенно; раз в 12 часов тихо обновляется в фоне.
- Группы каналов слева, каналы справа, логотипы, номера. Группа открывается сразу при наведении.
- **Избранное** — удерживайте OK на канале (на планшете — долгое касание).
- **Поиск** по названию.
- Плеер на Media3/ExoPlayer: HLS, DASH, Smooth Streaming, MPEG-TS, MP4; поддержка `http-user-agent` / `http-referrer` из плейлиста; ссылки без `.m3u8` автоматически пробуются как HLS; повтор при обрывах сети.
- **Настройки → При запуске** (шестерёнка в шапке главного экрана):
  - *Список каналов* — открыть главный экран (по умолчанию);
  - *Последний канал* — сразу включить то, что смотрели последним;
  - *Канал из избранного* — включить первый канал избранного, ↑/↓ листают избранное;
  - *Выбранный канал* — конкретный канал (выбирается из списка с поиском, свой для каждого плейлиста).
  Срабатывает при открытии приложения, в том числе при повторном запуске с главного экрана ТВ.
- **Настройки → Автозапуск → «Запускать при включении ТВ»** — BapukTV открывается сам после загрузки устройства
  (и сразу включает канал по настройке «При запуске»). На Android 10+ для этого нужно разрешение
  «Поверх других приложений» — приложение само предложит его включить. Если на ТВ нет экрана этого разрешения:
  `adb shell appops set com.bapuk.tv SYSTEM_ALERT_WINDOW allow`.
  Срабатывает при загрузке системы; многие ТВ при нажатии кнопки питания выходят из режима ожидания, а не загружаются заново.

## Управление

| Где | Пульт | Планшет |
|---|---|---|
| Список | ← → между группами и каналами, OK — смотреть, удерживать OK — в избранное, «Назад» — к группам | касание, долгое касание |
| Плеер | ↑ / ↓ или CH+ / CH− — следующий / предыдущий канал | свайп влево / вправо |
| Плеер | — | свайп вверх / вниз: слева — яркость, справа — громкость |
| Плеер | OK или ← — список каналов поверх видео; ← ещё раз — категории (видео продолжает идти) | касание; нажать на заголовок списка — категории |
| Плеер | цифры — набрать номер канала | — |
| Плеер | → или INFO — информация о канале | — |
| Плеер | красная кнопка — растянуть / вписать картинку | двойное касание |
| Плеер | «Назад» — к списку каналов | «Назад» |

## Установка

Скачайте `BapukTV-<версия>-open-release.apk` со страницы [Releases](../../releases) и установите на ТВ
(через файловый менеджер, «Send files to TV» или `adb install`). Нужно разрешить установку из неизвестных источников.

## Сборка

Нужны JDK 17 и Android SDK (platform 36).

```bash
./gradlew assembleOpenRelease
```
### Сборки open и full

- **open** — обычная сборка, без встроенных плейлистов.
- **full** — то же самое плюс раздел «Готовые плейлисты» на экране «Плейлисты». Список задаётся файлом
  `app/src/full/res/values/presets.xml` (в репозиторий не входит):

  ```xml
  <resources>
      <string-array name="presets">
          <item>Название|https://example.com/playlist.m3u|https://mirror.example.com/playlist.m3u</item>
      </string-array>
  </resources>
  ```

  Зеркало необязательно — его пробуют, если основной адрес не отвечает. Собрать: `./gradlew assembleFullRelease`.

## Устройство проекта

- `M3uParser.kt` — потоковый разбор плейлиста (3000 каналов ≈ 0.1 с).
- `Repo.kt` — плейлисты, избранное, последний канал (файлы + SharedPreferences).
- `MainActivity.kt` — группы и каналы; `PlayerActivity.kt` — плеер; `PlaylistsActivity.kt` — добавление плейлистов; `SettingsActivity.kt` — настройки; `BootReceiver.kt` — автозапуск; `Presets.kt` — встроенные плейлисты (сборка full).
- `LogoLoader.kt` — загрузка логотипов с кэшем в памяти и на диске, без сторонних библиотек.

Зависимости минимальны: Media3 (ExoPlayer, HLS, DASH, SmoothStreaming, UI), RecyclerView, AndroidX Core/Activity, Coroutines.
